# 🎮 SpawnCore

O **SpawnCore** é uma plataforma de criação, hospedagem e gerenciamento de servidores de jogos utilizando containers Docker. Inicialmente focado em Minecraft, o projeto tem como objetivo permitir que usuários criem, controlem e monitorem seus servidores por meio de um painel web e de um bot do Discord.

## 🛠️ Stack Tecnológica

| Categoria | Tecnologias |
|---|---|
| Linguagem | TypeScript, Node.js |
| Backend | Fastify |
| Banco de dados | PostgreSQL, Prisma |
| Containers | Docker, dockerode |
| Frontend | React, shadcn/ui |
| Bot do Discord | discord.js |
| Testes | Vitest |
| Infraestrutura | Docker Compose, Caddy |
| CI/CD | GitHub Actions |
| Observabilidade | Prometheus, Grafana |

## 🚀 Status do Projeto

**Fase 1 em andamento: fundamentos**

Nesta etapa, o foco está no aprendizado e na aplicação de Git, terminal Linux, TypeScript e HTTP.

O objetivo inicial é desenvolver um script em TypeScript capaz de iniciar e desligar um servidor Minecraft utilizando Docker.
